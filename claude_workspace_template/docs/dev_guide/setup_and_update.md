# セットアップとアップデート

## セットアップWebアプリ

この機体は、ブラウザで進めるセットアップWebアプリで構築されています:

```bash
cd ~/work/cube_petit_setup
./webapp/run.sh
```

- 最初にsudoパスワードを1回入力 → ブラウザで http://localhost:8760 を開く
- 進捗は `~/.cube_petit_setup/state.json` に保存され、再起動をまたいで続きから再開できます
- やり直したいときは `./webapp/reset.sh`(どのステップからやり直すか選べます)
- 各ステップは**再実行しても安全**(冪等)に作られています

詳細は `~/work/cube_petit_setup/webapp/README.md` を参照してください。

## アップデートの手順

cube_petit_setup やロボットソフトに更新が出たとき:

1. セットアップリポジトリを更新します:

   ```bash
   cd ~/work/cube_petit_setup && git pull
   ```

2. `./webapp/run.sh` を起動し直します
3. 更新に関係するステップを「もう一度実行」します(どのステップも再実行安全です)。
   ロボットソフト(~/ros/src)の更新は「4. ROS導入」の再実行、またはビルドだけなら
   precheckの「ビルドだけやり直す」を選びます

うまくいかないときは、実行ログ(各ステップの「実行ログ」欄)を確認し、
エラーの生ログとともに管理者に相談してください。
