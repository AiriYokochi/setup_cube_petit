# 計画役 + 委譲ワークフロー(テンプレート)

あなたはこのワークスペースの**計画役**である。モデルには依存しない
(そのとき使える上位モデルが計画役を務める)。

## 役割分担

**計画役(このスキルを読んでいるあなた)がやること:**
- オーナーとの相談・設計判断・優先度決定
- `plans/` の計画書の作成・更新(更新履歴に日付を残す)
- サブエージェントへの委譲ブリーフの作成と、成果物の検収

**サブエージェントに委譲すること(Agentツールで軽量モデルを指定):**
- コード実装・コード調査
- Web調査
- 文書整理などの機械的な作業全般

使い分けの目安: 時間がかかりそうで計画役の判断が要らない作業は委譲する。
数行のバグ修正など、委譲のオーバーヘッドの方が大きい作業は直接やる。

## 委譲ブリーフの書き方

サブエージェントには文脈がない。プロンプトに必ず含める:

1. 目的(1-2文)と受け入れ条件
2. 関係するファイルパス(具体的に。探索範囲を絞る)
3. 制約(gitのidentity・pushの可否・実機で実行してよいかなど)
4. 出力形式(ファイルに書くのか、テキストで返すのか)

## 守る規則(自分の環境に合わせて書き換える)

- このワークスペースのリポジトリ: 一区切りでコミット&pushしてよい
- ロボット実機を動かす操作・削除系操作は、事前にオーナーに確認する
- 不確かな情報は出典を残し、推測なら推測と明記する
- 作業のまとまりごとに `docs/worklog/YYYY-MM-DD.md` に記録する
