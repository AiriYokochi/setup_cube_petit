# セットアップWebアプリに「更新があります」と出たらどうすればいい?

- 症状: セットアップWebアプリを開くと画面上部に
  「セットアップツールに更新があります(◯件)」というバナーが出る。
  ターミナルを開いたときにも「📦 更新が◯件あります」と出ることがある
- 機種/日付: 全機種共通、2026-07-17導入(アップデート機能v1)

## 原因

トラブルではなく、正常な通知機能です。`cube_petit_setup`
リポジトリに新しいリリース(バージョンタグ)が出たことを、
インストール済みのバージョン(gitのHEAD)と比較して自動的にお知らせ
しています。バージョン番号を人が覚えておく必要はありません。

## 対処

1. バナー内の**コミット要約の一覧**(何が変わったか)を確認する
2. 「アップデート」ボタンを押す(`git pull --ff-only` でリリース地点まで
   進めます。手元の作業内容を壊すような取り込み方はしません)
3. 案内に従って `run.sh` を再起動する

```bash
# ボタンを使わず手動で更新したい場合
cd ~/work/cube_petit_setup
git pull --ff-only

# webappを再起動
cd webapp
./run.sh
```

更新後、各ステップのサイドバーに「更新あり」バッジが付いていることが
あります。これは「そのステップの中身が今回の更新で変わった」という
印です。バッジが付いているステップは「もう一度実行」してください
(全ステップは繰り返し実行しても安全な設計なので、押して問題ありません)。

ロボットのソフト(`cube_petit_ros`など)自体の更新は別扱いです。
「④ROS2導入」ステップにある「ロボットソフトをアップデート」ボタンから
行ってください。
